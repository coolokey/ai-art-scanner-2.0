# AI 藝術能量掃描儀 2.0 (AI Art Energy Scanner 2.0)

> 🎨 **生成式 AI 輔助之跨領域美感評量與創客實踐系統**  
> Multimodal Neural Aesthetic Evaluation & Maker Badging System

---

## 🌟 核心特色

1. **評審快速通道（免 API Key 極速體驗）**：
   - 內建專家評量規準（Rubrics）與高品質示範畫作，評審與學生無需輸入金鑰即可一鍵體驗。
   - 亦支援自訂 Google Gemini Vision API（1.5 Flash / 2.0 Flash）。
2. **六大專業美育素養指標**：
   - 主題契合與符號語意 (35%)
   - 構圖重心與結構張力 (20%)
   - 色彩冷暖與豐富度 (15%)
   - 明暗立體與光影層次 (15%)
   - 筆觸細節與線條質感 (15%)
3. **獨家三大 AI 視覺化疊圖診斷**：
   - **三分構圖法則線（Rule of Thirds）**
   - **AI 視覺重心熱區（Visual Focus）**
   - **主調色彩色票卡（Extracted Palette）**
4. **實體創客輸出閉環（Maker Badging）**：
   - 達標 85 分直接解鎖 **標準 58mm 胸章印刷版型**（含正面可視區、金屬包邊出血線與十字裁切標記）。
   - 一鍵動態生成 **特級繪師·AI 藝術能量認證證書**（300 DPI 高解析圖檔）。
5. **班級星空數位藝廊**：
   - 即時典藏達標胸章作品，支援全班大螢幕策展瀏覽。
